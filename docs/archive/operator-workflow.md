# Operator workflow\n\nThe dashboard is a read-oriented view over persisted run evidence. It labels all traffic as synthetic k6 traffic and keeps lifecycle state separate from report availability.\n\nQueued and running runs expose a `Cancel run` action. The dashboard requires explicit browser confirmation before calling `POST /api/v1/runs/{run_id}/cancel`, then refreshes both the run list and selected detail. Completed, failed, canceled, and aborted runs do not expose cancellation.\n\nFailed and canceled runs remain visible with their timestamps and retained reason. They do not expose report or artifact links unless a persisted report exists. Cancellation retains any partial files for operator inspection; it never turns a run into a passing report.\n\nThe dashboard does not initiate external load tests, alter Azure resources, or infer real-user behavior from synthetic results.\n
