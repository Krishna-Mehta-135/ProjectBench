## Architecture and local workflow

- React/TypeScript/Vite in `apps/web`. Rust/Axum with SQLx/PostgreSQL in `apps/api`. k6 is the load generator. Run artifacts use durable filesystem storage. Keep the modular monolith and PostgreSQL unless a measured need calls for another service.
- Read `PRD.md`, `docs/hld.md`, `docs/lld.md`, `docs/run-api.md`, `docs/report-format.md`, `docs/onboarding.md`, `docs/local-deployment.md`, and `docs/safety.md` as relevant. Main implementation files are `lib.rs`, `runner.rs`, `orchestration.rs`, `storage.rs`, `artifacts.rs`, `report.rs`, and `timeseries.rs` under `apps/api/src`.
- From ProjectBench, run `docker compose up -d postgres`. With `DATABASE_URL` set to the local Compose database, run `cargo run -p metrics-api`. Set `METRICS_WEB_ORIGIN=http://127.0.0.1:5173` and `METRICS_ALLOWED_ORIGINS=https://api.canvassync.tech,https://api.knowdex.me` for the known local setup. The API has historically bound to `0.0.0.0:8080`, so keep it on a trusted local network and require `METRICS_OPERATOR_TOKEN` before any shared exposure. `/ready` checks database readiness.
- In `apps/web`, run `npm ci` if dependencies are missing, then `VITE_API_ORIGIN=http://127.0.0.1:8080 npm run dev -- --host 127.0.0.1 --strictPort`. Preview at `http://127.0.0.1:5173/`. If the port is occupied, check the existing process and align API CORS with the actual frontend origin. Avoid stopping unrelated processes.
- Validate with `cargo fmt --check`, `cargo test` with the local database configured, `npm test`, and `npm run build`. The fixture `tests/fixtures/bin/k6` must stay executable. Browser-check desktop and mobile, keyboard navigation, project links, and the Lab. Exercise run success, failure, and cancel against isolated fixtures before using external targets.
- Import `config/projects/*.registry.json` via `POST /api/v1/projects/import` only if the projects are absent. Every import creates a new project identity. Both projects were already imported into the prior local DB and their environments were intentionally disabled.
